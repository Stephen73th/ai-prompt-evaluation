# PROMPT MATTERS
## A Comparative Evaluation of AI Tools and the Impact of Prompt Design on Output Quality

## Project Overview

Prompt Matters is a collaborative AI experimentation project investigating how different generative AI tools respond to identical tasks and how prompt design influences the quality of their outputs.

The project compares two AI tools, ChatGPT and Google Gemini, across five task categories using basic prompts and improved prompts. The resulting outputs will be evaluated, documented, and analysed to identify differences in performance, instruction-following, usefulness, and limitations.

This project is an experimental research and presentation project. It does not involve building a software application.

## Project Aim

To compare the responses of two generative AI tools across different tasks and investigate how prompt design influences the quality, relevance, accuracy, and usefulness of AI-generated outputs.

## Objectives

1. Evaluate two generative AI tools across five different task types.
2. Compare outputs generated from basic prompts with outputs generated from improved prompts.
3. Assess AI responses using consistent evaluation criteria.
4. Identify the strengths, weaknesses, limitations, and unexpected behaviours of each AI tool.
5. Communicate the findings and practical lessons about prompt engineering through a final presentation or video.

## Research Questions

- RQ1: How do ChatGPT and Google Gemini differ in their responses across different task types?
- RQ2: How does improved prompt design influence output quality compared with basic prompts?
- RQ3: Which AI tool demonstrates stronger performance across the evaluation criteria used in this experiment?
- RQ4: What common limitations, errors, or unexpected behaviours emerge during the experiments?
- RQ5: What practical lessons can users learn about writing effective prompts when interacting with generative AI?

## Experimental Design

The experiment uses five task categories. Each task is tested using a basic prompt and an improved prompt on both AI platforms.

| ID | Task Category | Primary Evaluation Focus |
|---|---|---|
| T1 | Knowledge & Explanation | Accuracy and clarity |
| T2 | Summarisation | Information extraction and meaning preservation |
| T3 | Creative Writing | Creativity and constraint adherence |
| T4 | Reasoning & Problem Solving | Logical correctness and explanation |
| T5 | Complex Instruction Following | Constraint compliance and completeness |

### Experiment Size

- 5 task categories
- 2 prompt versions per task
- 2 AI platforms
- 20 total AI outputs

## Evaluation Criteria

Responses will be evaluated using a 1–5 scoring scale across the following criteria:

| Criterion | Description |
|---|---|
| Accuracy | Correctness of information or reasoning |
| Relevance | Alignment with the task and prompt |
| Completeness | Coverage of requested requirements |
| Clarity | Understandability and organisation |
| Instruction Following | Compliance with prompt requirements |

The maximum score for an individual response is 25 points.

For the complex instruction-following experiment, an additional constraint compliance rate will be calculated based on the number of explicit requirements successfully satisfied.

## Conclusion

Prompt Matters explores the relationship between AI capability and prompt quality through a structured, evidence-based comparison. By testing identical tasks with different prompt strategies across two AI tools, the project aims to demonstrate how prompt design can influence AI output and why AI responses should be critically evaluated rather than accepted without review.
